# Project Olympus 

Laboratorio personal de automatización , infraestructura , observabilidad y seguridad. 

## Objetivo 

Construir una plataforma reproducible para aprender y demostrar competencias en: 

- Linux 
- Git y GitHub
- Ansible
- AWX 
- Terraform
- Docker 
- Cloud
- Observabilidad
- Hardening y automatización de seguridad


## Arquitectura inicial

- Windows 11 como sistema anfitrión.
- WSL2 Ubuntu como estación de ingeniería.
- Visual Studio Code como interfaz de desarrollo. 
- VMware como laboratorio de servidores.
- Git para control de versiones.
